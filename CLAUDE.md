# invonics-visionary-hub

The Invonics Technologies marketing site.

## Stack
TanStack Start, TypeScript, Vite, Tailwind, shadcn/Radix components. Deployed on Cloudflare (`wrangler.jsonc`, `@cloudflare/vite-plugin`). Content via Cosmic CMS (`@cosmicjs/sdk`). Code in `src/`, serverless code in `functions/`, build-time SEO in `scripts/`. Schema notes in `SCHEMA.md`.

## Commands
- `npm run dev`
- `npm run build` runs `generate-seo` first (sitemap and JSON-LD, uses Node's native TS stripping, not tsx) then `vite build`.
- `npm run lint`, `npm run format`.

## Rules
- Do not use `npx tsx` in build scripts, it was replaced on purpose.
- Sitemap `lastmod` values and JSON-LD structured data are generated, do not hand-edit generated output in `dist/` or `public/`.
- `google2d264f203364123c.html` is the Google Search Console verification file. Keep it.
- Cosmic keys go in env, never in the repo.

## Deploy
Cloudflare. Sydney's standing rule is Railway for production apps and Vercel for static showcases. This one is on Cloudflare already, confirm before moving.
